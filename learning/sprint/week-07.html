PII and trust-boundary pass

This is genuinely your strength — apply it here on purpose. What sensitive data does your app touch, where does it cross a trust boundary, and how is it protected at each crossing?

  1. List every piece of data in the app you'd be uncomfortable seeing leaked.
  2. Mark each trust boundary it crosses — client to server, server to Claude, server to storage.
  3. Write one line per boundary: what protects it today, and what doesn't yet.
